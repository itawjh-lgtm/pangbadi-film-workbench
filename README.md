## 启动

### 现有电脑继续使用

原工作台地址：<http://127.0.0.1:8767/>。原目录内双击 `启动工作台.command`，或使用已经安装的 `~/Applications/造梦工作室.app`。本次未更名或重打包该 Mac 外壳。

### 从交付包 / GitHub 快照启动

在本项目目录运行：

```sh
bash scripts/start-portable.command
```

默认访问 <http://127.0.0.1:8768/>；使用包内 `prompts/` 角色快照和独立 `data/portable-runtime/` 数据目录。保持终端开启，按 Ctrl+C 停止。也可双击该 `.command` 文件。

基础页面需要 Python 3；本次验证使用 Python 3.14。文字生成需要安装并登录 Codex CLI；RunningHub 生成需在工作台本地配置页填写自己的 Key。**克隆仓库不会带回已有项目或密钥，也不会自动发起付费生成。**

原启动方式默认读取 `~/自己学习/提示词/影视Agent团队提示词/` 与 `游戏Agent团队提示词/`。`prompts/` 是此次交接的 25 份原文快照，包含 21 个角色、两份共享指令和两份目录；没有覆盖原提示词库。

## 当前能力

- 21 个伙伴工位、角色原文、对话与项目协作；真实文字执行由本机 Codex CLI 完成。
- 影视固定六阶段协作：R11 → R03 → R05 → R04 → R06 → R11；支持团队连续完成文稿和分步审阅。
- 项目内人物资产、横向创作画布、提示词编辑、美术优化、风格、比例与清晰度参数。
- RunningHub 工作流和模型接口、提交与查询、图片和视频预览；供应商可用性、账户权限和价格须以实际响应为准。
- 任务依赖、成果汇总、主展示选择、回收站、恢复/永久删除/批量清理、本机持久化。
- 银白玻璃界面、21 位可爱角色图、首页案例与示范、可调布局和可隐藏讨论区。

## 开发检查

```sh
node --test tests/*.test.cjs
node tests/views.smoke.cjs
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

Node 用于前端测试；Python 测试需允许绑定本机回环端口。测试使用临时数据和模拟提供者，不发起付费生成。测试结果和未通过项见交接验证记录。

`scripts/build-preview.py` 是历史聊天内嵌预览构建器；当前内容超过 1 MB 上限，暂不可成功构建。日常网页运行不依赖它。处理图片的旧脚本另需 Pillow 或其脚本内声明的工具；原生 Mac 构建需要 Apple Swift / Command Line Tools。
