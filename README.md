## 启动

### 继续本机已有项目

在原项目目录双击 `启动工作台.command`，打开 <http://127.0.0.1:8767/>。既有 Mac 客户端继续访问同一后台。为保留本机配置，原安装路径 `~/Applications/造梦工作室.app` 与 Bundle ID `cn.dreamstudio.workbench` 保持不变；当前客户端源码显示名称为“夏夏工作台”。

### 从 GitHub 或交付副本试运行

在项目根目录执行：

```sh
bash scripts/start-portable.command
```

默认访问 <http://127.0.0.1:8768/>，使用包内 `prompts/` 和独立的 `data/portable-runtime/`，不接管原 8767 项目。保持终端开启，按 Ctrl+C 停止。

需要 Python 3；文字生成需要安装并登录 Codex CLI；图片／视频生成需要在本机配置页填写自己的 RunningHub Key。**克隆源码不会带回已有项目、参考图或密钥，也不会自动开始付费生成。** 原启动方式读取 `~/自己学习/提示词/影视Agent团队提示词/` 与 `游戏Agent团队提示词/`，包内保留 25 份岗位相关原文快照和一份说明。

## 当前能力

- 21 位伙伴工位、岗位原文、项目对话和文字交接；影视六阶段自动协作，支持连续完成文稿或分步审阅。
- 人物资产先于镜头图制作；姓名介绍、定妆提示词、美术优化和采用版本分别管理。
- 横向创作画布、每镜图片／视频节点、风格、比例、清晰度与批量生成。
- **参考图片窗口**：人物资产或图片卡点击“参考图”，选择／拖入 PNG、JPG、WebP；每图最大 10 MB、每节点最多 10 张，可选参考用途并写说明。先保存本机，生成准备时上传给 RunningHub；模型实际图数限制仍需满足。
- **站内大图预览**：点击图片先查看，支持缩放、拖动、适应窗口、原始尺寸和独立下载入口。
- RunningHub 工作流／模型 API、报价、提交、状态查询与图片／视频结果展示。
- 项目成果汇总、主展示选择、回收站恢复和永久删除、本机持久化。

参考图上传、保存、刷新回读、大图与真实参数组装已有 2026-10-26 验证；这不代表已完成付费参考图生成和质量验收。详见[参考图实施记录](docs/plans/2026-10-26-reference-images.md)。

## 独立云端版本与未完成范围

发布仓库的 `online/` 是独立云端 BYOK 源码（使用访客自己的 Key），并非本机服务自动转成线上。**本次 GitHub 源码推送不等于重新部署云端，也不证明旧线上入口当前可用或已完成生成验收。** 本机新增的大图／参考图功能不能据此推断已同步进云端；以 `online/` 自身实现及独立部署记录为准。

仍未完成或未验收：RunningHub 国际站 Image 2 专门接入；自动剪辑合成成片；可运行游戏自动制作；多人共同编辑；Mac 自包含分发与公证；完整人物定妆→镜头图→视频链路的最新真实质量验收。`lib/media-posters.js` 仍未接入首页，不能算自动精彩帧封面已完成；首页成果两倍大展示需求仍需独立实现／验收。
