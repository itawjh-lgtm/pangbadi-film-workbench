# 庞巴迪影视工作台 · 云端试用版

现有工作台的在线执行版本。沿用首页、21 位员工、项目协作、人物资产与横向画布；使用每位访客自己的模型 API Key。

## 试用方式

1. 打开部署链接，使用 ChatGPT 登录。
2. 点顶部「模型连接」，填写自己的文字模型服务、模型名称与 API Key；可选 DeepSeek、通义千问、OpenAI。
3. 填写 RunningHub **模型 API 对应密钥**。个人工作流密钥与模型密钥可能不同，请以 RunningHub 管理页权限为准。
4. 新建项目，选择团队连续协作或逐步审核。员工真实调用所选文字模型；模型的搜索、文件和外部工具能力不会自动开放。
5. 核对文稿、人物设定与分镜；先在「人物资产」生成并采用定妆图，再到「创作画布」生成镜头图和视频。提示词、风格、画幅、清晰度保持可编辑。
6. 图片和视频返回后可在项目中预览、打开和下载。供应商链接可能过期，重要成果请及时下载。

保存密钥只保存配置；主动启动写稿或生成才会调用对应服务。费用由模型服务商向该 API 账号收取。工作台不提供共享免费额度，报价也不等于账户扣费上限。

## 运行边界

- 桌面版继续使用本机 Python + Codex；云端版使用 HTTP 文字模型 + RunningHub。桌面与云端分别存储，不会自动上传你的本机项目、密钥和数据库。
- 文字协作由浏览器轮询推进；关闭页面会暂停后续阶段，重新打开可继续核对。供应商已受理的图片/视频任务会继续运行。
- 结果不明确的提交不会自动重试，以免重复扣费。先去供应商任务列表核对。
- 生成、返回文件、预览播放、用户验收是不同状态；示例项目不代表真实执行结果。
- 模型目录保留已知下架标识；其余模型的当期可用性以供应商返回为准。此版使用中国站固定接口，没有把个人密钥自动转发到国际站。
- 当前未提供在线剪辑合成、长期媒体托管或多人实时共编。

## 技术与数据

- Vinext + Cloudflare Workers；D1 存储账号隔离的工作台、运行记录、文稿、画布和配置。
- Sites 网关负责 ChatGPT 登录。服务端每次从网关注入身份确定数据 owner，不接受请求体传入的 owner。
- 访客密钥经 AES-GCM 加密后存入 D1，账号 ID 作为加密附加认证数据。`VAULT_SECRET` 只配置在托管环境。
- 前端配置响应只有「是否已保存」状态。密钥不回显、不入浏览器存储、不入 Git；更换文字服务商须重新填写对应密钥。
- 批次/请求 ID 在外部提交前持久化；数据库版本检查防止旧页面覆盖新修改。
- 浏览器缓存按账号隔离。请勿在共享电脑上把已登录账号交给他人使用。

## 本地开发

需要 Node 22.13+，建议 Node 24/25。首次按 Sites 官方安装流程安装依赖。公共界面通过 `node scripts/sync-workbench.mjs` 从本机工作台白名单复制；运行数据、私密连接文件和 QA 目录不会复制。

1. 本地 `.dev.vars` 填写随机生成的 `VAULT_SECRET`（至少 40 字符，不提交）。
2. `npm run db:generate` 只在数据库结构变化后生成新迁移。
3. 按 Sites 构建流程构建，再用 Wrangler 把尚未应用的 `drizzle/*.sql` 应用到本地 D1。
4. `npm run dev` 启动。仅本机开发使用 starter 提供的模拟登录。
5. 运行 `node scripts/test-cloud.mjs` 与 `npx tsc --noEmit`。

部署由 Sites 源码、归档和版本发布流程完成，保留当前 `.openai/hosting.json` 的项目身份。不要公开本机 8767 端口，也不要把本机 `data/runtime` 打包进云端。
