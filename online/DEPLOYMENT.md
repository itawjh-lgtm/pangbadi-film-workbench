## 如何使用

登录后点击「模型连接」，填写自己的文字模型 Key 和 RunningHub 模型 API Key；新建项目，选择团队连续完成或逐步审核；确认文稿后先做人物定妆，再生成镜头图与视频。结果归到对应项目、人物和镜头。费用由访客各自的模型账户结算。
