# RunningHub 接入与试用

打开正式工作台 **http://127.0.0.1:8767/**。「工具与连接」负责配置；创作、进度和结果在「项目协作」的分镜、任务、素材中。Mac 客户端共用同一份本机配置与任务记录。

## 先用个人账号 API

当前按用户选择沿用已保存的个人会员 Key，不开通企业服务，不自动更换密钥。官方消费级 API 支持 AI 应用与工作流；本工作台当前实现的是其中的 **ComfyUI 工作流** 接口，可用于生图和生视频。

1. 在个人 API 连接区测试账户连接。保存成功与测试通过是两个状态；测试连接不创建生成任务。
2. 进入真实项目的「分镜」，选择某镜的「生成图片」或「生成视频」；也可从「素材」「任务」直接新建不绑定镜头的生成任务。编辑窗自动带入当前镜头已有提示词，并显示固定归属。
3. 在编辑窗选择「个人 API / 工作流」，粘贴可访问的生图或生视频 **工作流链接或 ID**，读取参数，明确选择接收提示词的字段。RHTV 无限画布链接不是工作流 ID，不能直接替代。参考素材需要先准备成该工作流接受的格式；当前没有通用文件上传入口。
4. 连接页填写工作流参考单价，编辑窗填写本次预算。预览费用和参数，确认后提交一次。工作流参考价不是官方实时报价。
5. 到本项目「任务」查询排队、运行、失败或完成状态；在「素材」预览实际返回的图片或视频。绑定镜头及原稿版本的结果也会显示在对应分镜中。查询仍需手动点击，不显示推测的百分比。

分镜卡片从项目当前 R04/R06 源文稿提取，并保留原稿链接。未支持的文稿格式会显示提示；不会编造镜头。镜号相同但原稿版本不同的结果仍保存在项目素材中，不混作当前镜头结果。编辑窗草稿在当前页面关闭、重开时保留；刷新整页后不保留未提交草稿。

尚未选择工作流时，接口已接好，但不能凭提示词直接推断应该执行哪个工作流及哪些节点。不会伪造生成结果。

## 独立模型接口备用

此入口不要求工作流 ID，服务端已登记四种已核验能力：

| 模型 | 能力 | 输入 |
| --- | --- | --- |
| 全能图片 G-2 官方稳定版 | 文生图 | 提示词、画幅、清晰度、质量 |
| 全能图片 G-2 官方稳定版 | 图生图 | 提示词、1–10 张公开 HTTPS 图片链接、画幅、清晰度、质量 |
| Seedance 2.5 | 文生视频 | 提示词、画幅、清晰度、时长、声音开关 |
| Seedance 2.5 | 图生视频 | 首帧链接、可选尾帧、提示词、清晰度、时长、声音开关；画幅跟随首帧 |

官方规定独立模型 API 使用「企业级共享」Key，不能把现有个人会员 Key 填入模型通道。此类型名称不等于必须购买企业套餐，但本轮按用户要求不配置或使用它。

将来启用模型通道后，费用预览会调用官方 price-preview，只报价、不生成。改变模型或参数后需重新报价；报价过期需刷新。查询失败显示未知，不当作免费。预算用于提交前检查，不能保证服务商最终扣费封顶，最终以 RunningHub 账单为准。

## 可视化平台与结果边界

「打开无限画布」进入 RunningHub RHTV；[本次试用画布](https://www.runninghub.cn/project/canvas/2114061166822531074)使用网页登录。画布任务与本机 API 任务目前不自动同步，网页成功不等于 API 成功。

本机任务保存项目关联、实际输入、平台任务编号、状态与结果链接，不保存密钥。未知提交不自动重试，应先到平台核对，避免重复扣费。结果预览不代表已经下载、完成播放检查、质检或剪辑；员工文字协作也不会自动提交付费媒体任务。

连接配置保存在 data/runtime/connections.json，权限 0600，不写入浏览器存储。不要把配置文件或完整密钥发到聊天或公开仓库。

## 扩展接口

- GET /api/media/models：已登记模型与参数定义。
- GET /api/projects/{id}/storyboard：本项目源文稿提取的镜头、提示词和来源。
- POST /api/media/estimate：按 mode 选择工作流参考估价或模型官方报价。
- POST /api/media/jobs：带确认、预算及估价 token 提交。
- POST /api/media/jobs/{id}/refresh：使用任务原来的模式与凭据类别查询。

新增模型在 server/media_models.py 登记固定官方路由和参数；不接受客户端任意传入 API 主机、认证头或回调。缺省 mode 的旧请求继续使用工作流。调用这些本机写接口需页面的 X-Studio-Token。
