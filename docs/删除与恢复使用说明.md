# 删除与恢复

不想保留的内容可以直接移入回收站。工作台保留原稿与记录，恢复后回到原来的位置。

| 内容 | 删除入口 |
| --- | --- |
| 项目 | 左侧项目名旁，或项目页顶部的垃圾桶 |
| 任务与决策 | 任务看板卡片旁的删除按钮 |
| 文稿、手工成果、图片和视频 | 对应成果或素材卡片上的删除按钮 |
| 工作对话、本地便笺、自动协作 | 对应记录上的删除按钮 |
| 画布节点 | 卡片顶部垃圾桶，或右侧参数面板底部 |
| 多个画布节点 | 勾选节点后，点击底部“删除所选” |

普通内容直接移入回收站；项目删除会先说明影响范围。左侧导航与画布工具栏都有“回收站”，点击条目旁的“恢复”即可找回。普通卡片删除后的短暂提示也提供“撤销”。

删除整个项目会隐藏其任务、文稿、素材和画布。恢复项目后，此前单独删除的内容仍留在回收站，需要单独恢复。

删除画布节点不会同时删除它生成过的素材。视频引用的图片节点被删除时，会提示先恢复参考图或更换图片；恢复会保留原提示词、参数、位置和引用。

正在执行、排队提交或结果未知的关联内容，需先停止未提交任务，或等待/核对已提交结果，再删除。删除本身不会取消 RunningHub 的任务，也不会重新生成。

## 彻底删除与清空

回收站同时支持三种操作：

- 单条：点击该项旁的“彻底删除”。
- 批量：勾选不再需要的条目，点击“删除所选”。
- 全部：点击“清空回收站”，处理当时回收站中的可恢复条目。

以上操作都会先列出本次删除范围，并明确提示“无法从回收站恢复”。点击“取消”保留原内容；只有点击最后的“确认彻底删除”才执行。确认期间不重复提交，失败时保留错误说明和可重试入口。清空针对确认时的条目，不会顺带清理后来新增的回收站内容。

彻底删除项目会同时清理本工作台中归属于该项目的内容；删除协作或运行记录也会处理其所属记录与本地文件。被彻底删除的内容不能通过恢复项目、旧缓存或旧快照重新出现在工作台。

仍被任务、决策、画布节点或制作流程引用的内容会阻止彻底删除。请按提示先解除依赖，或将相关内容移入回收站后在同一批中处理。执行中、排队或结果未知的关联任务，以及尚未完成的项目同步，也会阻止清理；不会只删除可处理部分而悄悄跳过冲突项。

清理范围限于本工作台本地内容，**不会删除 RunningHub 平台上的文件，也不会取消平台上的任务**。已有导出文件、独立备份和其他外部副本保留。彻底删除不等于清除这些外部副本。
