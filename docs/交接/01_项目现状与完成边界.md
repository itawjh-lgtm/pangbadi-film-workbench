# 夏夏工作台：项目现状与完成边界

整理日期：2026-10-29。本文以本机正式工程当前代码为准，区分功能实现、历史验证、真实生成和线上部署。

## 1. 当前交付与入口

用户担任总策划，影视 R01—R16 与游戏 G01—G05 共 21 位岗位伙伴参与文字工作。影视项目通过六阶段文稿协作进入人物资产、分镜、图片与视频画布。岗位提示词不会自动赋予外部工具权限，也不表示 21 个角色一直同时执行。

| 入口／目录 | 用途与数据边界 |
| --- | --- |
| 本机 `http://127.0.0.1:8767/` | 原正式项目，读取原 `data/runtime/`；GitHub 整理不迁移或覆盖它 |
| 既有 Mac 外壳 | 访问本机服务；保留 `造梦工作室.app` 路径与 `cn.dreamstudio.workbench` 标识；当前源码品牌为夏夏工作台 |
| `scripts/start-portable.command` | GitHub／交付副本试运行，默认 8768，使用独立 `data/portable-runtime/` 与 `prompts/` |
| GitHub 公开仓库 | 代码、界面资源、提示词、历史设计、测试和说明；不是私有项目备份或运行中的网站 |
| 发布包 `online/` | 单独维护的云端 BYOK 源码，不自动继承最新本机改动；本次推送不执行云端重新部署 |
| 历史桌面交付与私有备份 | 保留当时快照，不能因新仓库更新而推断它们已经同步；含密钥和真实项目的私有备份不得公开 |

## 2. 本机已实现的能力

| 模块 | 当前行为 | 边界 |
| --- | --- | --- |
| 岗位与对话 | 独立工位、项目上下文、岗位原文、最多 4 人依次文字交接 | 工位与项目上下文分开；未接自动联网调研和真实画质质检 |
| 文字执行 | 使用已安装并登录的 Codex CLI | 返回文稿和代码文本，不自动运行游戏或发布作品 |
| 自动协作 | R11 → R03 → R05 → R04 → R06 → R11；暂停、继续、审阅、定点返修、历史稿 | 固定影视六阶段，不是任意 21 人自由编排 |
| 审核方式 | 连续完成文稿／逐步审核，最终需要总策划认可 | 连续模式不自动批准媒体费用 |
| 人物资产 | 姓名、介绍、定妆提示词、美术优化、生成、采用与版本引用 | 先完成需要的人物定妆，再生成含人物的镜头图 |
| 参考图片 | 人物和图片节点上传／拖入；整体、外观、服装、构图动作、画风色调；每图说明 | 每图 10 MB、每节点最多 10 张；模型总参考图上限另外校验；视频继续使用现有首帧流程 |
| 创作画布 | 横向镜头编排、图片／视频节点、平移缩放、节点拖动、批量操作、参数与提示词编辑 | 生成素材，不自动剪成完整影片 |
| 大图查看 | 站内弹窗、滚轮缩放、放大拖动、适应窗口、原始尺寸、独立下载 | 远程链接过期时需要回项目处理；预览成功不等于离线备份 |
| RunningHub | 模型目录、动态参数、报价、提交、查询；个人工作流接口 | 目录存在不等于当前账户有权限或所有接口已实测 |
| 成果与回收站 | 项目归属、主展示／最终成片标记、软删除、恢复、单条／批量永久清理 | 标记不代替专业验收；本地删除不删除服务商云端文件 |

参考图先保存在本机。生成准备时上传给 RunningHub，并将用途与说明加入实际提示词；已采用的人物定妆仍保留在前。添加、修改、移除引用使旧报价失效。缺少兼容图生图接口时明确提示，不随意换用其他厂商或已下架模型。

## 3. 模型与外部服务

本地模型目录含 311 个操作路径（图像 99、视频 212），其中代码标记可用 305、禁用 6；这是接口操作数，不是独立模型数，更不是全部付费实测结果。运行时仍可能根据服务商明确下架响应继续禁用接口。实际价格、权限、可用性以当前供应商响应为准。

默认图片链使用 Seedream V5 Pro 文生图／图生图，镜头视频默认 Seedance 2.5 图生视频并使用本镜成功图片。模型 API 与个人工作流 Key 按接口要求区分保存；个人账号也可能持有平台称作“企业级-共享”的模型 Key。

RunningHub 国际站 Image 2 的专门接入尚未完成。外部无限画布仅作为跳转入口，外部任务不会因此自动回填本机。没有把中国站凭据自动转发到其他站点。
