# 庞巴迪影视工作台：项目现状与完成边界

整理日期：2026-10-25。本文对应本次交付的源代码，不把历史设计图、测试夹具或已写好的提示词当作实际成片。

## 1. 当前交付是什么

这是提供本机工作台和云端 BYOK 试用两种入口的影视与游戏团队工作台。BYOK 指使用各自的 API Key。用户担任总策划，21 位有岗位指令的伙伴参与文字工作；影视项目可串联六阶段文稿协作，再进入人物资产、分镜和图片／视频创作画布。

本机版本由 HTML/CSS/JavaScript 前端、Python 标准库服务、SQLite 与本地运行文件组成。Mac 0.6 已安装，提供本机／云端双入口。云端试用使用 Vinext、Cloudflare Worker 与 D1，已具备登录身份、每账号数据隔离和个人 Key 加密保存，并已部署上线。云端个人项目不自动迁移或同步本机正式项目；账户隔离不等于多人共同编辑同一项目。Mac 客户端也尚未验证为可任意复制分发的自包含安装包。

| 交付位置／入口 | 用途 | 数据边界 |
| --- | --- | --- |

| 桌面交付的 `01_源码与资源` | 源码、界面资源、岗位快照、说明及启动脚本；GitHub 同步对象 | 不含正式密钥、真实运行库和私有输入 |

## 3. 模型与配置现状

2026-10-25 对当前 `server/media_models.py` 的只读核对：登记 **311 个接口，其中图像 99、视频 212**；代码目录当前可选 **305**、禁用 **6**。其中包含生成、编辑和处理操作，不等于 311 个独立基础模型。本机运行时还可能根据已确认下架错误禁用具体接口，实际可选项以当前页面为准。

模型直连使用 RunningHub 标为“企业级-共享”类型的 Key；个人账号也可持有这种 Key，不代表必须开通企业账户。消费级个人 Key 用于工作流通道，两类凭据分别保存。模型直连通常不需要工作流 ID；工作流方式必须有实际工作流和提示词字段映射。中国站已明确下架的 G2／Ultra 具体文生图接口已停用，不扩大到同系列所有接口，也不自动切换国际站。

默认人物与纯场景图使用 Seedream 5 Pro 文生图；含人物镜头使用对应图生图接口和已采用定妆；镜头视频使用 Seedance 2.5 图生视频，引用本镜当前成功图片。模型必须实际可用且参数通过校验，默认值不代表已为所有题材验证质量。

本次没有接入 RunningHub 国际站 Image 2，也没有把普通无限画布网址转换成模型 API。外部 RunningHub 画布中的任务暂不自动同步成本地项目记录。
