`assets/projects/` 的四组示范素材分别是：

- `lighthouse-cover`：灯塔海岸与红衣角色的案例主视觉。
- `storyboard`：分镜示范。
- `character-sheet`：角色设定示范。
- `game-level`：游戏首关示范。

每组均保留 PNG 与 WebP。另有 `home-visual-reference.png` 和 `home-deliveries-reference.png`，来自用户提供的首页视觉参考。正式首页会裁取其中部分图片区域，交互、文字和按钮由代码实现；修改排版应改 `lib/views.js` 与首页 CSS，不是在参考截图上叠不可编辑文字。

PNG 是可继续编辑的位图，不能视为带图层的 PSD、Figma 或三维源工程。当前没有找到与这些角色图对应的 PSD、AI、Blend 或可编辑 Figma 文件交付。能完整复用的是位图、角色外观描述、提示词记录和网页源码。

## 7. 模型目录、接口与外链

`docs/api/runninghub/` 当前有 7 份公开资料文件，包括原始索引、3 份 JSON 目录/schema、采集器及说明。目录采集于 2026-10-24，可能随服务商更新而过时。

- 311 个唯一模型操作路径，图像 99、视频 212，包含生成、编辑、参考图、工具和视频处理，并非只有文生图/文生视频。
- 当前代码禁用 6 个操作；静态公开文档原标下架 4 个，另 2 个由代码记录的实际中国站下线状态补充。
- schema、显示名称、能力分类和默认参数可以本地查看；权限、价格、可用性和生成质量仍须外部服务响应与实际结果验证。
- 已实现 RunningHub 工作流 API 与模型 API；无限画布仅有外部平台入口，平台画布任务不等于能自动回传本地。
- RunningHub 国际站 Image 2 的专门接入未完成。其他平台目录或成本登记入口不等于该平台 API 已接通。

主要外部依赖与链接类别：

| 类别 | 来源 / 边界 |
|---|---|
| RunningHub 中国站 | `https://www.runninghub.cn/`，含模型/工作流 API、官方文档、平台画布与账单页面 |
| 远程生成结果 | API 返回的服务商 HTTPS 链接，可能过期、限权或不支持外链；没有自动离线副本 |
| 其他媒体工具平台 | `server/media.py` 的 providers 目录；当前非 RunningHub 项均标记不支持 API，主要为链接/参考成本 |
| Codex | 本机 CLI 及其账户连接；没有将其可执行程序或账户凭据随源码再分发 |
| 用户研究参考 | 飞书岗位原文来源、网页设计与平台参考链接等保留在历史资料；不是当前网页必须联网加载的 UI 依赖 |

界面本地图片和系统字体可随源码展示，但文字生成与外部媒体调用需要网络及用户自己的账号配置。

## 8. 许可、保密与交付核验

本包没有统一开源许可证，也没有为所有参考截图、角色提示词或历史示范图提供完整商业再分发授权证明。生成记录可说明来源和制作方式，不能替代平台使用条款或权利核验。外部发布时需分别确认用户提供资料、参考截图、平台返回结果及依赖软件的授权；不要把未知许可写成免费商用。

私有运行目录、连接密钥、账号登录资料与实际项目附件不进入代码仓库。历史 `docs/qa/` 可能含真实用户项目和账户证据，本次移入桌面本地私有备份的 `historical-qa/`；其内容不在此重述，也不以素材目录名义公开。

验收本清单时：

1. 用全量 CSV / JSON 清单确认文件存在、大小及 SHA-256，区分正式文件和历史副本。
2. 检查 R01—R16、G01—G05 的大图、缩略图、显示资料和角色原文一一对应。
3. 区分本地设计示范、远程真实生成结果和测试媒体，不能混算作品数量。
4. 需要离线保留的真实媒体另行下载并验证，记录其所属项目、任务、版本和来源；仅保存 URL 不算完成离线归档。
5. UI 或角色图修改后更新相应清单、说明和测试，保留能够说明采用版本的来源映射。

更多运行和数据恢复步骤见 [部署备份与恢复](06_部署备份与恢复.md)。
