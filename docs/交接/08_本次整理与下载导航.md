# 夏夏工作台：源码与素材下载导航

整理日期：2026-10-29。GitHub 仓库沿用原地址 [itawjh-lgtm/pangbadi-film-workbench](https://github.com/itawjh-lgtm/pangbadi-film-workbench)，显示品牌为夏夏工作台。仓库文件夹名和历史记录中的旧品牌不影响启动。

## 下载后从哪里开始

1. 在 GitHub 点 **Code → Download ZIP**，解压整个目录。不要只下载 `index.html`，页面需要同目录内的脚本与素材。
2. 阅读根目录 `README.md`，或用浏览器打开 `docs/交接/00_交付导航.html`。
3. 使用本机版：运行 `bash scripts/start-portable.command`，打开 `http://127.0.0.1:8768/`。数据写入解压目录的 `data/portable-runtime/`，不接触原电脑 8767 的项目库。
4. 文字执行需要自行安装、登录 Codex CLI；生图生视频在本地工具连接页配置自己的 RunningHub Key。启动、阅读文档不会自动生成或扣费。

## 发布范围

仓库包含工作台的代码、界面视觉素材、提示词快照、示例、设计历史及操作文档。本机实际项目、用户上传参考图、生成记录、账号凭据、数据库、日志、历史真实账号截图和已安装应用构建产物留在本地，不属于公开素材包。

`online/` 保留独立云端代码及历史发布记录。本次推送 GitHub 不等于部署网站，也不表示本机新功能已移植到云端；需要部署时应单独确认配置、运行测试并发布。公开仓库也不等于已授予所有素材的再分发或商业授权。

逐文件清单在整理发布副本时生成，记录相对路径、分类、字节数与 SHA-256。下载后可运行 `python3 scripts/package-handover.py --verify .` 检查文件完整性；建议在启动或产生新运行文件之前执行。
