# 夏夏工作台：用户操作手册

整理日期：2026-10-29。本文介绍当前本机版。操作顺序为“新建项目 → 自动协作文稿 → 人物资产 → 分镜 → 创作画布 → 成果汇总”。分镜文稿可以先产生，含人物的镜头图制作需要先采用人物定妆。

## 1. 启动与版本

| 用途 | 打开方式 |
| --- | --- |
| 继续本机真实项目 | 原项目目录双击 `启动工作台.command`，或使用既有 Mac 客户端；网页为 `http://127.0.0.1:8767/` |
| 试用 GitHub／交付副本 | 项目目录执行 `bash scripts/start-portable.command`；默认 `http://127.0.0.1:8768/` |
| 阅读交接资料 | `docs/交接/` 中的 HTML 导航和 Markdown 手册 |

便携副本使用独立 `data/portable-runtime/` 和包内 `prompts/`。原 8767 使用原运行数据；不要覆盖原数据库。双击 `index.html` 只打开静态文件，不能代替 Python 后台。

文字任务需要本机已登录 Codex CLI，图片／视频需要自己的 RunningHub 连接。仓库不附真实密钥。`online/` 是单独云端版本，不能用本手册推断它已同步最新本机功能；本次源码推送不重新部署线上，也没有验证旧线上入口当前可用。

## 2. 页面分工

| 页面 | 用途 |
| --- | --- |
| 总策划台 | 上方案例与示范，之后真实项目成果和待处理事项；示范与真实生成结果分开 |
| 项目协作 | 自动协作、人物资产、分镜、画布、任务、素材、版本、成果汇总 |
| 任务看板 | 管理责任人、复核人、依赖和拍板 |
| 团队伙伴 | 查看 21 位伙伴岗位，打开独立工位 |
| 工具与连接 | 检查文字执行器、配置 RunningHub、测试连接、打开外部平台 |
| 回收站 | 恢复、单条／批量彻底删除、清空 |
| 数据备份 | 导出／恢复项目 JSON；不是完整运行库及媒体备份 |

首页作品仍以最近 4 份卡片排列。两倍大封面与自动挑选视频精彩帧尚未完成，不能将历史设计图当作已经上线的行为。

## 3. 新建项目与审核模式

1. 点击“新建项目”，填写项目名、简报、项目类型和伙伴。
2. 选择“团队连续完成”或“逐步审核”。前者连续完成文稿后总审；后者在剧本、美术设定、最终文稿节点等待审核。
3. 创建后进入“自动协作”，说明已经带入。需要调整时展开项目说明，不用重填需求表。
4. 点击“按现有说明开始”。创建项目本身不会调用模型。

影视自动流程：R11 制作规划 → R03 剧本 → R05 美术设定 → R04 分镜 → R06 提示词 → R11 汇总。游戏伙伴可做工位与项目文字协作，当前固定流程不自动制作可运行游戏。

## 4. 审核与返修文稿

- “认可这版，继续”：确认当前版本。美术稿批准后可准备人物资产。
- “交回修改”：写明保留什么、修改什么；旧稿会保留。
- “修改这个阶段”：返修已完成阶段，上游变更会影响下游。
- “暂停协作”／“继续协作”：控制后续执行；失败后排除原因再从本步继续。
- “发起新一轮协作”：已有一轮结束后开启下一轮，不要靠重复新建项目解决文稿问题。

出现版本冲突先读取最新稿。当前文字执行器不会自行浏览网页、检查真实画质或发布；必要资料正文应放入项目说明或对话，未经核实的信息注明待核实。

## 5. 人物资产与参考图窗口

逐步模式确认美术稿后进入人物资产，连续模式在总审后准备人物。表中姓名介绍与定妆提示词分开，员工头像不会充当作品人物。

1. 核对人物是否齐全，缺少时“＋ 新建人物”，填写名字、介绍与定妆提示词。
2. 点击“提示词编辑”修改描述；“美术优化”可向 R05 提要求，确认应用后才更新提示词。
3. **点击人物行的“参考图”**，选择文件或拖入图片。
4. 为每张图选择“整体参考、人物外观、服装造型、构图动作、画风色调”，并填写希望保留／改变的部分，例如“参考发型和外套剪裁，背景重新设计”。
5. 可点缩略图查看大图，也可移除引用；“放大编辑 ↗”扩大窗口，“还原窗口 ↙”恢复。看到保存完成后再离开。
6. 用“画质／风格”调整生成参数，选择人物后单张或批量生成；查看本批报价后确认。
7. 图片返回后检查，满意再“采用这张定妆”，或“整组采用定妆”，随后进入分镜。

参考图支持 **PNG／JPG／WebP，每张不超过 10 MB，每节点最多 10 张**。每图说明最多 1,000 字；模型可能对“已采用人物图 + 上传参考图”的总张数有更小限制，页面会校验。重复选择同一图会保留用途和说明，不重复添加。

图片先存本机，生成准备时才上传 RunningHub。有参考时自动选可用的同系列图生图接口，并保留兼容的尺寸和清晰度；没有兼容接口会提示调整模型。参考图与文字可以指导结果，但不保证完全复刻或自动通过质量验收。

移除参考只解除当前节点引用，历史原图不会立刻永久删除。节点或项目进入回收站时不能继续访问其参考图；恢复可重新访问；彻底删除时会清理对应本地原图。人物设定改变后需重新生成并采用当前版本，旧镜头成果仍保留供核对。

## 6. 画布生图与生视频

文稿确认后带入镜号、图片／视频提示词、来源与默认模型，每镜有图片和视频节点。默认图片为 Seedream V5 Pro，含人物镜头带入已采用定妆；默认镜头视频为 Seedance 2.5 图生视频，使用本镜当前成功图片作首帧。

1. 核对人物和分镜，再进入创作画布。
2. 图片卡片可点“参考图”补充构图、姿态、场景或风格参考，用法与人物参考窗口相同。已有采用的人物参考仍保留。
3. 点击“画质／风格／提示词”调整本镜；勾选需要的图片并“生成所选”，查看本批费用后确认。
4. 图片成功后检查，再生成对应视频。缺少当前有效首帧时不能开始图生视频。
5. 不满意可修改提示词、参数或参考图，重新报价生成；旧结果保留在项目素材中。

视频节点本轮沿用现有首帧引用流程，参考图窗口用于人物和图片节点。添加、修改、移除参考会使旧报价失效；上传未完成时不能生成。不必每张图重新填写模型接口表单，但每批费用确认仍独立于文稿审核。

### 画布与布局

拖动空白处平移、卡片顶部改位置；缩放按钮或 Control／Command 配合滚轮缩放，“全览”查看全局。顶部导航定位镜头，图片在上、视频在下。可以新增自由图片／视频节点，收起右侧编辑器或讨论区，拖动分隔线调节支持的栏宽。专注模式铺满工作区，退出或 Escape 返回。

## 7. 参数与提示词

| 参数 | 操作与边界 |
| --- | --- |
| 图片比例 | 常用 9:16、16:9、1:1、3:4 等；按当前模型支持范围展示 |
| 清晰度 | 按模型提供 1K／2K 等选项，改变清晰度保留比例；像素在高级设置查看 |
| 视频参数 | 分辨率、时长、声音、草稿等按实际模型 schema 展示 |
| 内置风格 | 可选择风格或保持原稿；“查看画面与风格提示词”查看这两部分，参考用途说明由后台另行加入 |
| 批量参数 | 只对兼容同类节点应用；保留各自比例，不覆盖提示词与参考 |
| 更换模型 | 高级设置中选择；必须满足新接口的图片输入等必填条件 |
| 提示词优化 | 人物交 R05、镜头交 R06；应用建议才修改草稿 |

目标镜头时长与模型生成素材时长不同，工作台不会自动裁剪。改模型、参数、提示词、参考、选择或预算后重新报价；单纯平移与移动卡片不会主动使报价失效。降低清晰度是否更便宜，以新报价为准。

## 8. 模型连接

进入“工具与连接”，将自己的模型 API Key 保存并测试；日常无需重复配置。RunningHub 个人账号可能持有平台称作“企业级-共享”的模型 Key，名称不等于必须开通企业账户。

- 模型 API：填“模型 API 密钥”，保存并测试，回项目选择模型和参数，取得官方报价。
- 个人工作流：展开可选连接，填消费级个人 Key、工作流链接／ID和参考单价，测试并读取实际节点参数；提示词必须映射到正确节点。
- 无限画布链接不是工作流 ID。“打开无限画布”仅跳转外部网页，外部任务不自动回填本地。

人物／图片参考窗口支持本地图片上传，但它不是所有模型、工作流、视频都通用的任意附件接口。其他输入仍按具体接口要求填写。已下架项禁用时不要强行重试；国际站 Image 2 尚未专门接入。

测试连接不会生成。报价和预算不是服务商实际扣费硬上限，任务未知时先查原任务编号与平台记录，再决定重试。密钥只填本机配置页，不发聊天或提交仓库。

## 9. 看大图、进度与成果

- **点图片先看大图**：弹窗内滚轮缩放，放大后拖动，使用“适应窗口”或“原始尺寸”；Escape／关闭返回。
- **要下载时再点“下载原图”**：远程地址的保存行为受浏览器与服务商响应影响，检查文件是否实际保存。
- 画布显示排队、执行、成功、失败或未知状态，不编造过程百分比。
- 项目“任务”看执行编号和错误；“素材”看已返回图片／视频；末尾“成果汇总”看主展示与各项结果。
- 可“设为主展示”或将视频“设为最终成片”；这是展示选择，不代表自动剪辑、专业质检或发布已完成。

远程图无法加载可在弹窗重试；如果地址过期，应回项目检查该结果。能够播放不等于已经离线备份。

## 10. 伙伴与手动任务

团队伙伴工位可单独对话；项目内可 `@姓名`、`@R03` 或最多选择 4 人依次协作。独立工位不自动带入当前项目。便笺只记录内容，手动任务的责任人、复核人、依赖和拍板各自管理；模型输出文字不会自动代表用户认可。

## 11. 删除与备份

普通删除进入回收站；“恢复”找回，“彻底删除”“删除所选”“清空回收站”先显示不可逆范围。被引用、执行中、排队、未知或未同步内容需先解决阻塞。永久清理不删除 RunningHub 云端、外部导出或独立备份，也不会取消供应商任务。

本机运行目录含数据库、连接配置、原始参考图和运行附件，应一并私有备份；项目 JSON 不是完整备份。云端、本机 8767、便携 8768 相互独立，不会因切换入口而迁移。恢复前备份目标并停目标服务，勿直接覆盖运行中的库。远程结果要另行保存原文件，只有链接不能算完整素材归档。

## 12. 常见问题

| 现象 | 处理 |
| --- | --- |
| 网页打不开 | 核对 8767／8768 与对应启动脚本，不让副本抢正式端口 |
| 团队没开始 | 创建只建项目，需在自动协作点击开始；检查 Codex 登录 |
| 参考图无法添加 | 检查格式、10 MB、张数、节点归属；不要在示范项目上传 |
| 加参考后模型提示不兼容 | 选可用的图生图接口，满足其总图数上限；不要绕过禁用状态 |
| 刷新后内容不一致 | 先处理保存状态或版本冲突，不反复覆盖；保留本页副本 |
| 不能生视频 | 检查本镜成功首帧、人物版本和模型必填参数 |
| 任务未知／超时 | 查原任务及供应商记录，避免重复扣费 |
| 想一键出完整影片 | 当前产出镜头素材，剪辑、配音、字幕和最终导出还需外部工具 |

参考窗口的上传、保存、预览已有历史交互验证；本轮代码整理没有发起新的付费生成。首次试用可从一位人物、一张镜头图和一个短视频开始，分别检查费用与质量。
