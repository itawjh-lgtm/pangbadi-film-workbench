## 5. 发布包核验

1. 读取当轮整理导航与素材清单，区分正式代码、设计历史和私有运行资料。
2. 对照全量文件清单中的相对路径、字节数和 SHA-256；确认公开包不含运行库、连接密钥或用户上传原图。
3. 用便携启动脚本在独立端口和数据目录运行，不覆盖原正式库。
4. 查看实际 GitHub 提交与文件内容，确认推送目标和最终提交标识；不要用本地提交代替远端成功证据。
5. 私有备份与云端部署分别核验，不因为源码已发布而改写它们的状态。
