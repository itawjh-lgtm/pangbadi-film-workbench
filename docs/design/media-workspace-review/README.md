## 提示词工作窗 · 2026-10-25

右侧“画面描述 → 展开编辑”或“视觉风格 → 编辑提示词”打开三栏编辑窗：左侧选风格，中间编辑主体、风格描述和避开项，右侧检查最终正向与独立负向提示词。

- 内置10种风格：电影写实、可爱3D、日系动画、黏土定格、水彩绘本、水墨国风、像素游戏、扁平科普、未来科幻、清透摄影。
- 切风格仅替换风格描述和附加约束，保留主体与用户补充要求。自定义风格仅存风格，不带当前主体。
- 可直接编辑全文；后续上游变化保留手动稿并明确提醒尚未合并。重组后可恢复上次手动稿。
- 图片、视频的主体、画幅与提示词分别保存在浏览器。视频单独提供动作与镜头描述。
- 确认窗显示实际将使用的提示词；手动稿与新设置不一致时给出提示和编辑入口。
- 当前仍为设计预览，未接入实际生成。风格卡为色卡与图形标识，既有灯塔示例图不会随选择重绘。
