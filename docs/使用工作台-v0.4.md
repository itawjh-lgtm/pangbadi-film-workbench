# 开始使用造梦工作台

双击项目根目录的 `启动工作台.command`，打开 http://127.0.0.1:8767/ 。保持原来的 127.0.0.1 地址，避免不同来源的浏览器存储不一致。

## 和员工一起工作

1. 在「团队伙伴」打开某人的工位，输入工作要求，选择“对话”或“产出”，点执行。岗位全文会自动加载，不需要你再复制提示词。
2. 需要协作时，在「项目协作」选项目、加入成员。影视默认 R11 接收，游戏默认 G01；也可以用 @ 或成员选择指定执行者。
3. 选择“依次协作”，按顺序勾选最多 4 人，例如编剧 R03 → 导演 R04 → AI 影像 R06。后一个人能看到前面已保存的完整交付。
4. 运行卡显示排队、执行、交付和失败。可以停止，或等待完成后继续补充要求。暂不支持中途把新指令注入正在运行的模型。
5. 打开真实成果，阅读完整正文、下载 Markdown，或点“继续修改”产生新版本，旧稿保留。

“本地便笺”只记录你的想法，不会调用模型。旧示例仍标示例。模型调用使用本机已登录的 Codex 账户及其额度，不等于无限免费。

## 从任务看板执行

任务需要明确责任人与不同的复核人。依赖任务未完成、方向未拍板时，执行按钮会提示阻塞。完成文字产出后，任务不会自动变为完成；你仍需核对交付、专业复核证据和验收意见。

## RunningHub 两种方式

「工具与连接」提供“打开 RunningHub”可视化入口，以及 API 配置和生成区。

你选好工作流后，在本机配置页填 API Key、工作流 ID、整次调用估算单价和币种。密钥只存本机服务端，不要发在聊天里。节点输入使用工作流实际 nodeId/fieldName/fieldValue；无需覆盖时填 `[]`。

填写本次预算 → 预览费用与参数 → 勾选确认 → 提交一次。之后点“查询服务商状态”，打开返回的结果链接。预估不是平台报价，预算不是平台账单硬上限；实际费以 RunningHub 账单为准。未知结果先到平台核对，避免新建请求造成重复扣费。

## 数据与恢复

- 刷新页面能读回已保存的运行与成果；关闭网页不会取消后台文字任务。
- 关闭启动窗口不会关闭服务；电脑休眠或服务退出会影响在途执行。
- 重启后中断任务会显示失败/中断，请查看已保存稿件后重新发起。
- 浏览器 JSON 备份保存项目、任务和人工记录；后端数据另在 `data/runtime/`。
- 双击 `index.html` 或聊天内嵌预览只适合浏览和便笺，真实执行请使用上面的本机网址。
- 如果未连接：先双击启动器，再在「工具与连接」刷新；检查本机 `codex login status` 与网络。

目前可真实生成文稿、剧本、分镜文字、提示词、方案及代码文本。图片/视频 API 需要你选择工作流并配置 RunningHub；没有配置时不会生成或扣费。其他媒体平台、自动剪辑合成、多人同步、云端发布和本平台节点画布仍需后续接入。
