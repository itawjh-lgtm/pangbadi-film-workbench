# 创作画布

项目按“文稿／美术设定 → 人物资产 → 分镜 → 创作画布”的顺序使用。人物资产是独立列表，用来管理本作品的角色定妆；创作画布按镜头展示图片和视频。已有文稿与媒体的项目可从对应入口继续。

## 从文稿开始

1. 在“自动协作”完成剧本与美术设定。使用分步审阅时，R05 美术稿经你批准后即可进入“人物资产”，不必等最终文稿总审。
2. 在独立的“人物资产”列表查看已提取的角色。名字与简洁介绍用于认识人物；定妆提示词在独立编辑窗口中修改。首次只勾选待做人物；图片返回后可整组采用或单张确认。来自占位稿的人物仍是内部测试形象，不能当作已核实的原作角色。
3. 查看“分镜”中的镜头内容与提示词。R05 批准后，后台文字分镜仍可能继续编写；当前没有“人物图片确认后才允许编写文字分镜”的调度硬闸。
4. 最终文稿确认后，创作画布会准备完整镜号对应的图片和视频节点。例如 `S01-001` 与 `S01-002` 是两个独立镜头，每镜图片在上、视频在下，并带对应提示词。含人物镜头需先采用所引用人物的定妆图。
5. 默认模型、画幅和视频素材时长已预设。点击某镜的“生成图片”“生成视频”，或使用“生成所选”；需要时可修改提示词、画质和风格。
6. 查看本批预计费用与明细，确认一次后执行所选任务。预算核对可选；填写后用于检查预计金额是否超出预算。
7. 任务状态和媒体结果返回对应节点，并保留在该项目的素材和任务中。

导入文稿、排列节点和修改提示词不会提交生成任务。只有确认批次后才向 RunningHub 提交。

新确认版本会准备对应的制作入口；重新打开历史文稿不会反复抢走当前页面。同步期间如果切页、继续输入或打开弹窗，工作台会保留当前操作，可稍后从人物资产或创作画布入口继续。连续执行模式没有独立的 R05 用户审批时，人物提取仍需等待最终用户总审，不能把自动完成当作你的批准。

新建影视项目时可直接选择“团队连续完成”或“逐步审核”，默认逐步审核。选择会随项目保存并带入首次自动协作：连续模式完成文稿后统一交你审核；逐步模式在剧本、美术设定与最终文稿处等待你确认。两种模式的生图、生视频均在人物资产和创作画布继续制作。

“自动协作”直接复用创建项目时填写的说明，协作方式始终显示在开始区域，可以在启动前调整。尚未开始时点击“按现有说明开始”；需要修改说明时再展开“查看或调整项目说明”。协作运行、待审阅、暂停或失败时，页面显示当前进度与已有操作，不重复要求填写新需求。完成或取消后，“发起新一轮协作”默认收起，由你主动展开再开始；有未提交的草稿时优先使用草稿选择，否则新一轮沿用上一轮方式。纯游戏项目继续使用团队对话安排制作。

## 人物介绍与定妆提示词

- 人物列表的“人物名字与介绍”只放姓名和简洁介绍，用于了解身份、性格与辨识特征。它不会直接截取整段执行提示词，也不会把表格分隔符、生成要求或禁止项当作人物介绍；缺少可用内容时显示“暂无人物介绍”。
- 新建人物时，分别填写“人物名字”“人物介绍”和“定妆提示词”。介绍用于认识人物；提示词控制外貌、服装、画风与定妆生成要求。调整或应用提示词建议不会同步覆盖人物介绍和原始文稿。
- “美术优化”打开独立大窗口，左侧查看当前定妆候选或已采用图片，右侧编辑提示词并填写优化要求。没有图片时保留空状态，不以员工头像代替作品角色。
- 点击“放大编辑 ↗”扩大窗口，点击“还原窗口 ↙”恢复；“完成编辑”、右上角关闭按钮或 Escape 可退出编辑窗口。窗口中的修改仍沿用自动保存与保存状态提示。
- R05 返回的优化建议可先查看、再编辑，点击应用后才替换当前提示词。尚未应用的建议不会触发生图；草稿已改动时，旧建议不会直接覆盖。

## 默认方案与修改

- 默认图片使用 Seedream 5 Pro：定妆及纯场景使用文生图，含人物分镜使用图生图并自动绑定已确认定妆。人物默认 1536×2048；9:16 镜头默认 1152×2048。明确宽高时不再同时传入会覆盖尺寸的 `resolution`。视频默认 Seedance 2.5 图生视频，自动取同镜当前成功图片作首帧。
- 修改人物造型会使原确认失效。更换定妆后，需要重做受影响分镜；旧图与旧视频保留，但缺少当前人物版本证据的旧图不能继续当首帧。
- G2 官方文生图及旧 Ultra 官方文生图在中国站已返回下架错误，这两个已知下架接口已禁用。此结论不扩大到同系列所有图生图接口。系统不会自动切换全球站、密钥或重复提交失败任务。
- 每镜保留自己的图片、视频提示词。通过卡片的提示词入口编辑；大窗口支持放大，常用画质与风格仍可从参数面板调整。修改会自动保存到本机，原始文稿保留。
- 默认保持原稿风格，也可从 31 种内置风格中选择，并通过“查看实际提交提示词”核对最终内容。
- 画质控件常驻编辑面板顶部。图片常用区使用画面比例（9:16、16:9、1:1、3:4 等）和清晰度；Seedream 支持 1K／2K，宽高像素移入高级设置。切换清晰度保留当前比例，非标准比例显示为自定义，不因查看页面改变参数；可用范围按当前模型约束。视频按真实模型能力提供分辨率、时长、声音与草稿参数，并区分原生分辨率和超分档位；模型不支持的能力不会作为通用承诺。
- 画质与风格可分别应用到勾选的同类项。批量画质仅作用于同模型节点，并保留每个目标原有比例，不改提示词和引用。风格应用独立于画质操作，不会顺带修改生成尺寸。
- 调低画质或缩短视频素材时长可作为控制成本的选择，具体差价仍以重新取得的官方报价为准。修改后旧报价失效，提交前会重新估价。
- “高级设置 · 更换模型与参数”默认收起，供更换模型、关联参考图及调整其余参数使用。
- **分镜时长**是成片中该镜的目标长度，**生成时长**是模型返回的视频素材长度。例如分镜需要 2 秒、模型最短支持 5 秒时，会生成 5 秒素材，后续剪辑取用。若目标超过模型支持范围，需要后续拆镜或剪辑安排，不能把素材时长视为已满足成片时长。

## 画布操作

- 首次进入默认使用专注模式，画布铺满窗口，批次操作显示在底部；点击“退出专注”或按 Escape 返回项目布局。主动切换的显示偏好会保留。
- 顶部显示镜头数量及图片、视频节点数量。点击镜头导航定位对应的图片、视频区域；“全览”查看所有镜头。
- 拖动空白处平移；拖动卡片顶部调整位置。
- 使用缩放按钮，或按住 Control / Command 配合滚轮缩放；“全览”查看整体。
- “＋图片”“＋视频”可以添加自由创作节点。
- 右侧编辑器可以收起；打开或收起编辑器、浏览高级设置，不会改变生成参数。
- 右侧“团队对话”可边查看进度边沟通，携带当前人物与镜头信息；“提示词”打开当前卡片编辑器，二者可切换。
- “人物资产”中的美术优化交给 R05，镜头提示词优化交给 R06；点击应用后才替换草稿。优化期间若又改了草稿，旧建议不会直接覆盖。
- 自动分镜视频无需重选模型和首帧。自由新增视频则按实际用途选择模型及其必需素材。
- “任务”显示排队、运行、失败、耗时和费用；“素材”只显示成功返回的媒体及文本产物。视频可在卡片播放或点击“放大播放”。

## 报价与任务

官方报价有时效。修改模型、提示词、参数、预算或所选节点后，需要重新计算费用。纯浏览、镜头定位、平移、缩放和调整卡片位置不会主动使报价失效；报价自然到期后仍需重新获取。

显示金额是本批预计费用，预算用于提交前核对，不能视为服务商实际扣费的硬上限。实际费用以 RunningHub 账单为准。

停止批次只停止尚未提交的节点。已经交给平台的任务继续查询结果。服务重启后会恢复已有任务的结果查询；未提交部分需要重新估价，结果不明的任务不会自动重复提交。

新一轮已确认文稿会形成新版本节点，保留旧节点上的用户编辑和历史结果。正式生成应使用当前已确认版本。

如果节点失败，查看该节点的错误原因和平台任务编号。没有明确结果时，先核对平台任务，再决定是否重新生成。

本轮使用隔离模拟报价与 UI 测试，没有新发起真实付费生成。新默认的实际出图、视频播放、画质及扣费结果，需在真实运行后分别检查。

## 首页和协作区域

- 总策划台首屏按已提供的参考构图展示：左侧为灯塔案例主视觉、项目信息、伙伴与示例进度，右侧为待拍板方案。封面与两张方案图使用参考图的三个图区；标题、伙伴、进度、方案按钮仍是读取当前状态的 HTML 控件。示例标签保留，不把参考图当作真实项目产出或完成证据。
- 真实项目成果位于首屏示范下方，默认展示最近最多 4 份成功图片／视频；桌面一行 4 张小卡，窄屏为 2 列或 1 列，只有 1 份也保持小卡尺寸。作品可播放、放大并进入对应项目素材。已删除、示例及失败任务不混入真实作品。
- 其后依次展示当前真实项目进度、文稿与规划、待处理和其他项目，可向下滚动。文稿只显示最近 3 条标题，全文从查看入口打开。
- 项目右侧“围绕作品协作”可用“收起协作”隐藏，在项目顶部点击“展开协作”恢复；切页和刷新保留本机显示偏好及对话草稿。
- 角色与视觉设定的交付文稿要求包含角色外貌、年龄、发型、服装、视图和定妆提示词；自动协作不额外展示人物说明或缺项面板。角色提示词、图片和修改操作统一在人物资产页。补充说明仍使用本阶段已有返修入口，不自动改写旧稿。

## 成果汇总

项目原“概览”改为导航末尾的“成果汇总”。影视项目仍先进入“自动协作”，项目内按以下顺序回看交付：

- **主展示位**：优先展示本项目最新成功视频，没有视频时展示最新成功图片；没有媒体则不造空白大图。图片完整显示，视频提供播放器。该展示位与首页四张小卡独立。
- **选择作品**：在下方生成结果中点击“设为主展示”，可选定一张图片或一段视频；视频另有“设为最终成片”，会把它置于主展示位并标注“你已指定”。这是总策划的展示选择，不改变任务复核、专业验收或发布状态。选择失效、被删除或不属于本项目时，回退为可用作品预览，不继承最终成片标记。
- **生成结果**：显示成功返回的真实缩略图或播放器，并区分定妆图、生成图片和视频片段。可查看素材或返回对应制作位置继续调整。
- **文字交付**：显示文稿标题、来源和审阅状态，点击查看全文。待审阅文稿不会标记为已验收；来自画布助手的已识别优化记录显示“提示词优化 · 员工名”，原文完整保留。
- **已完成任务**：默认收起并保留完成数量；展开后查看自动协作阶段交付、真实执行的本轮交付与手动登记完成。

未完成的项目也可查看已返回成果，并通过“继续制作”回到当前制作入口。没有成果时显示简短空状态。示例项目单独展示明确标注的示例视觉和记录，不混入真实成果。“素材”继续管理完整制作产物。

模型结果成功返回，只表示图片或视频素材已经返回，不代表成片制作完成、画质通过、用户验收或发布完成。
