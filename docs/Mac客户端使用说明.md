# 造梦工作室 · Mac 客户端

打开 `/Users/itawjh/Applications/造梦工作室.app` 即可使用。可将应用拖到 Dock，今后点击图标打开，无需先开 Codex 对话或手动运行终端命令。

## 开始创作

1. 点击“新建项目”，填写目标并选择影视或游戏团队。
2. 进入“项目协作”，输入需求。可使用 `@姓名` 或 `@R03` 指定伙伴，也可选择“依次协作”让最多 4 位伙伴交接。
3. 查看实际运行卡、事件与成果。成果可全文预览、保存 Markdown、继续修改，旧版本保留。
4. 单独找员工讨论时，从“团队伙伴”进入该员工工位。独立工位与项目对话各自保存。

## 常用操作

| 操作 | 位置 |
|---|---|
| 刷新页面 | `⌘R` |
| 重新连接后台 | `⌘⇧R` 或“显示”菜单 |
| 放大/缩小/恢复字号 | `⌘+` / `⌘-` / `⌘0` |
| 打开网页版本 | “显示 → 在浏览器中打开” |
| 查看数据文件夹 | “显示 → 显示数据文件夹” |
| 查看启动错误 | “显示 → 查看启动与运行日志” |
| 导出或恢复项目 JSON | 工作台左下“数据备份” |

## 保存与重开

网页与客户端连接同一台 Mac 的后台，项目、任务、便笺与手工成果自动同步。窗口大小和布局可各自保留。多个窗口同时修改遇到冲突时，系统停止覆盖并保留本页副本；提示中可导出副本，或选择数据库版本。JSON 备份不包含完整真实执行文件；完整备份需要保留 `data/runtime/` 目录。

关闭窗口不会结束应用，点击 Dock 可再次打开。`⌘Q` 退出客户端后，后台任务继续运行；重开应用即可查看。电脑关机后，未完成的本机文字任务不能从中途续跑，服务会保留已生成成果并记录中断。

## RunningHub

进入“工具与连接”，可跳转平台可视化操作。选定工作流后，在本机填写 API Key、工作流 ID、节点参数和参考单价，先预览费用，再确认提交。当前尚未配置真实工作流，也未验证付费生成。其他媒体平台入口保留，不能将入口视为 API 已接入。

## 本机版范围

本版已为当前 Apple Silicon Mac 构建。依赖原项目目录、现有 Python 3.14、已安装且已登录的 Codex CLI，以及两组岗位提示词目录。请保留这些文件的位置；应用菜单可直接找到数据。AI 生成仍需联网和模型账户额度。

安装包使用本地 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；尚不是可任意复制到其他电脑的独立分发版。运行不依赖保持 Codex 聊天窗口打开，但需要本机 CLI 的有效登录。
