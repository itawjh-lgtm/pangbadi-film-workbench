# 影视团队自动协作

打开「造梦工作室」Mac 客户端，进入一个影视项目，选择「自动协作」。网页也可使用 http://127.0.0.1:8767/ ，连接同一份本机数据库。

## 开始一次制作

1. 在「这次想做什么」填写作品需求：主题、受众、时长、风格、画幅、对白及必须保留的限制。已有资料可直接粘贴为文本。
2. 选择「逐步审阅」或「连续协作」。首次做项目建议逐步审阅，先确认剧本与视觉方向。
3. 点击「开始自动协作」。提交一次即可，团队依次完成六个阶段。

| 阶段 | 负责人 | 交付 |
|---|---|---|
| 制作规划 | 陆观行 R11 | 本次作品的制作简报 |
| 剧本创作 | 林砚舟 R03 | 完整剧本、旁白或动作脚本 |
| 角色与视觉设定 | 周予白 R05 | 人物、场景、道具和画面基准 |
| 逐镜设计 | 沈知遥 R04 | 带稳定镜号与时长的分镜表 |
| 生图与视频输入 | 姜云岫 R06 | 逐镜提示词及所需参考资料 |
| 交付整理与检查 | 陆观行 R11 | 文稿清单、冲突与下一步制作事项 |

每一阶段使用本机岗位提示词及共享指令全文，并读取前序阶段的真实成果。此版本使用固定流程；游戏项目继续使用原有工位与团队对话。

## 你需要做的决定

「逐步审阅」会在剧本、视觉和最终交付停下。点击成果卡查看全文，再选择「认可这版，继续」或填写具体意见后「交回修改」。连续协作会直接推进到最终文稿审阅。

已交付的阶段也可单独修改。修改剧本后，受影响的视觉、分镜和生成输入会按新版重新制作，旧稿保留在「历史版本」。审阅意见最多 2000 字。另一窗口更新了版本时，先查看最新成果，再确认继续使用当前版本，避免把旧意见发给新稿。

页面展示阶段、负责人、实际执行记录及文件，不使用估算百分比。阶段「已交付」只指这一阶段的文字输出完成，不表示媒体生成或整片验收完成。

## 暂停、失败与恢复

- 点击「暂停协作」可停止自动推进并取消当前在途文字调用，已交付文稿保留。
- 点击「继续协作」从未完成的阶段恢复，不重做已经完成且未受返修影响的阶段。
- 模型连接或额度错误会显示原因；排除问题后使用「从本步继续」。
- 关闭客户端窗口，后台通常继续运行；电脑休眠、关机或后台重启会影响调用。中断时保留记录，重新打开后检查状态并继续。
- 自动协作执行中，同项目的另一次手动模型调用会被阻止。等待审阅时可在右侧与伙伴讨论；需要改变本轮正式稿件时，应使用对应阶段的返修入口。

正式记录在现有 `data/runtime/studio.sqlite3` 中，文件在 `data/runtime/runs/` 中。页面刷新可恢复当前窗口的需求和审阅草稿；尚未提交的草稿不属于正式交付。完整备份应包含整个 `data/runtime/`，单独导出项目 JSON 不包含全部运行文件。

## 生图与视频

本轮自动准备剧本、视觉、分镜和生成提示词。点击「查看生成工具」可前往现有 RunningHub 配置与平台入口；选择实际工作流、填入节点参数并确认提交后，才能生成媒体。

这条自动协作流程尚未自动提交图片或视频任务，也不自动剪辑成片。文稿完成、媒体生成、实际播放、专业复核、总策划验收和发布分别记录。没有配置工作流时，界面会明确提示等待接入。
