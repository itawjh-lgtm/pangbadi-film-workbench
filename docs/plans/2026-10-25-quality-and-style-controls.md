# 画质与风格调整

沿用正式工作台和现有项目数据。人物资产独立于创作画布，位于分镜之前。

## 用户操作

- 人物资产与画布卡片使用“画质 / 风格 / 设定（提示词）”入口。
- 编辑面板顶部常驻画质区，按照所选模型的字段显示尺寸、分辨率、时长、声音等参数。
- Seedream 5 Pro 提供保持当前比例的 1K、2K 长边尺寸预设，也允许自定义宽高。调整像素尺寸时取消固定 resolution，避免服务商忽略宽高。
- Seedance 2.5 区分原生与超分辨率。打开草稿模式时切换到 480p；切换到更高分辨率时关闭草稿模式。
- 风格按类别展示，保留既有风格 ID 和原始提示词。风格描述只加入实际提交提示词，不替换原稿。
- 画质和风格分别支持应用到已勾选项。画质只复制给相同模型、相同媒体类型、相同人物/镜头类型的节点；风格不跨越当前页面作用域。

## 费用与数据

修改参数自动保存草稿，使旧报价失效；通过现有估价流程重新查询官方报价，用户开始生成前看到新报价。尺寸小不等于平台报价必然更低，不写固定优惠金额。

批量调整只修改画质或风格，不复制提示词、角色引用、首帧、随机种子或既有媒体结果。此项开发不运行真实付费生成。

## 验证

检查模型参数合法性、原比例保留、同类批量作用域、参考图保留、旧报价失效、刷新保存、实际提交提示词及常用字段无重复。使用临时数据库和禁止生成的模拟提供者进行交互测试；正式页只读验收。
