# 造梦工作室 Mac 客户端 · 0.5

用户已选择制作 Mac 客户端，沿用现有网页视觉与 21 位伙伴。

## 决策

使用 Swift / AppKit / WKWebView，产出真实 `.app` 和独立窗口。已有页面与 Python 执行服务保持同一套实现，不创建另一套角色库或项目库。

本轮面向用户当前 Apple Silicon Mac。客户端依赖现有项目目录、Python 3.14、已安装且已登录的 Codex CLI。应用使用本地 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证，不能当作跨电脑通用安装包。

## 启动与退出

应用自动调用 `desktop/service_manager.py ensure`。启动器用本机文件锁避免重复启动，健康检查核对服务名、项目路径摘要和版本；端口被其他程序占用时展示具体原因，不结束未知进程。旧服务不被自动终止。

首次升级先确认没有在途创作，再备份数据库并替换旧后台。日常打开应用自动启动或复用服务。关闭窗口或退出应用不结束后台任务；电脑休眠/关机仍会影响本机执行，不承诺离线或断电续跑。

## 数据

执行与生成记录仍存于 `data/runtime/studio.sqlite3` 和 `data/runtime/runs/`。项目、任务、便笺和手工成果从浏览器快照同步到同一数据库的版本表。新客户端先读数据库，不能用空白演示数据覆盖旧项目。浏览器首次迁移保留原 localStorage；并发修改使用 revision 比对，冲突保留副本并提示处理。

布局和窗口大小可以保留为每个客户端独立偏好。无需读取浏览器 profile；迁移通过正常网页启动流程触发。JSON 导出保留为恢复入口，不能替代对整个 runtime 目录的备份。

## 原生体验

独立窗口、应用图标、标准复制粘贴、Cmd-R 刷新、缩放、日志和数据目录入口。可信本机成果通过原生保存面板下载。RunningHub 等外链交给系统浏览器。网页没有执行 shell 或任意读写文件的原生桥。

## 验证范围

自动化：服务身份复用/占用防护、同步/CAS/恢复，以及原后端和前端回归。

实机：应用启动、旧浏览器项目迁移、显示真实运行记录、退出后重开、成果保存。AI 文字生成使用已有成功记录核验，不为客户端封装重复消耗模型；RunningHub 通用接口保留，等待用户选择工作流与本地填写密钥。
