# RunningHub 图像与视频模型全目录接入

用户要求：在当前影视工作台后台直接接入 RunningHub 的生图和生视频模型 API。

## 实施范围

沿用现有项目、分镜、素材、任务、Mac 客户端及本机服务。用官方公开 OpenAPI 文档构成固定接口目录，覆盖两套官方模型目录中的图像、视频生成及编辑处理操作。保留下架记录并禁止调用，不把音频专用、LLM 或工作流当成新的图像视频模型。

目录提供官方来源、参数 schema、调用/报价/查询路径和契约哈希。后端按原始 JSON 类型校验；前端按类型编辑参数，支持搜索、厂商/系列及用途筛选。模型直连和个人消费级工作流保持独立密钥。

生成仍从项目分镜或素材发起。项目、镜头、源稿和任务关系进入报价绑定与任务记录。官方报价需在有效期内确认，参数变化重新报价；保留预算检查、单次报价、请求幂等及未知提交状态不自动重试。

## 验证与交付边界

- 离线核对所有登记路径、schema、下架控制、参数类型和现有费用/项目回归。
- 使用用户账户已有共享 Key 验证连接和代表模型的官方报价；不创建新凭据。
- 本轮只接入和报价验证，不提交新的付费生成任务。
- 浏览器实页核验模型选择、参数编辑、项目归属，并将使用入口交付给用户。

公开目录详细数量和排除范围见 `../api/runninghub/README.md`；实际验证结果见对应 QA 记录。
