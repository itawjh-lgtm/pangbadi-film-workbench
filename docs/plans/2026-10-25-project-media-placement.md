# 项目内的分镜、媒体任务与素材

用户指出图片视频反馈位于“工具与连接”，脱离已有项目流程。本次沿用正式工作台的项目页和玻璃视觉，调整内容归属与操作入口。

## 页面职责

- 分镜：读取本项目现有 R04 分镜与 R06 生成输入，显示带原稿来源的镜头草稿；每镜可打开生图或视频提示词编辑窗。
- 素材：优先展示本项目实际返回的图片、视频；文稿单独列出。旧任务没有镜头关联时显示为项目素材。
- 任务：显示本项目生成任务的真实状态、参数、结果及查询入口，保留已有普通任务。
- 工具与连接：保存连接与工作流配置、验证和诊断，提供前往项目创作的入口。

## 关联与状态

生成请求固定项目，并可明确绑定项目任务、镜号、分镜原稿和提示词原稿。镜头内的结果必须匹配来源版本；旧版结果仍在项目素材与任务中保留。不同项目的素材不混用。无法解析的文稿保留原稿入口并说明原因。

提示词草稿可编辑；工作流节点由用户明确选择后才应用。沿用费用预览、单次确认与幂等提交，不自动付费生成。完成状态以服务商返回为准；平台托管结果不等于本地下载或用户验收。
