# 团队大厅改版规范

参考：用户指定 https://www.super-i.cn/tool.html 。本轮为既有团队概念的本地改版，接入21份员工人物图；真实Agent执行器仍未接入。

## 设计依据（浏览器实测）
- body：rgb(255,255,255)，字体 Poppins, PingFang SC, Microsoft YaHei, SourceHanSansCN, Montserrat, Tahoma, Arial。
- header：静态定位，高66.6562px（当前1265px视口）；导航、右侧胶囊按钮。
- h2 AIGC：85.3248px，weight600，黑色大标题。
- 内容列表 `.aigc3-list.grid-x4`：display grid，宽1146.66px，gap26.6624px，桌面四列。
- 单卡 `.item.show_login`：白底，1px solid black，border-radius20px，padding10.6624px，flex，gap8px，宽266.672px。
- 卡片标题：13.3376px，line-height18.6726px；原站随视口比例缩放，本地改版为可读性采用14—16px最小值。
- 选中强调：rgb(201,255,133)。非选中筛选胶囊为浅灰底。

## 布局与定制
- 用户定制优先于纯复刻默认：沿用视觉语言，内容替换为影视16岗与游戏5岗；品牌不复用Super-i标识。
- 页面顶栏：创作团队工作台；团队大厅、项目工作台、协作记录3个真实可切换导航；右侧“总策划 · 你”。
- 团队页：大标题TEAM，副标题影视×游戏；21成员统计只是角色数量。
- 状态带明确“概念演示 / 执行器未接入”，不能制造在线人数、实际制作任务和假增长。
- 筛选：全部21、影视16、游戏5、收藏；搜索按姓名、岗位和职责关键字。
- 4列员工卡：人物图（最终采用1:1完整人物展示），ID/团队徽标，虚构姓名，短岗位，真实职责摘要，两个能力标签，收藏按钮，打开工位按钮。针对用户补充的可爱Q版全身形象，完整保留头部与鞋子。
- 每位员工独立PNG原图，路径 `assets/employees/R01.png` 等。姓名和图像均是虚构员工形象，不是现实员工履历。
- 桌面最大内容宽1320px左右；平板2列；390px手机1列；320px仍可读，无横向溢出。
- 白色/近黑、荧光绿，细黑边，大圆角；允许匹配宿主的深色配色。

## 交互
- 原站筛选/搜索为点击或输入驱动，原站卡片会触发登录；本地用岗位工位弹层替换登录。
- 卡片打开真实可操作的本地详情弹层：人物、完整岗位、职责、输入、交付、复核与边界。
- 收藏、搜索、筛选仅影响本地展示；不触发AI或外部平台。
- 项目页延续《灯塔来信》六项模拟交接、方向拍板、复核和返修。
- 协作记录展示本地演示操作，不把演示记为真实生成/发布。
- 键盘可操作；模态框焦点可返回；移动端有效点击区域至少44px。

## 文件职责
- 页面与视觉：index.html、styles.css。
- 数据：data/employees.js，导出window.TEAM_EMPLOYEES。
- 主交互：app.js，由主代理整合。
- 人物原图与网页缩略图：assets/employees/、assets/thumbs/。
- 主页面容器ID、data属性和渲染插槽由页面建设者明确提交给主代理。
