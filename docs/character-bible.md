# 21位虚构团队员工设定 v1.1

用户始终是项目总策划。本设定含16位影视员工、5位游戏员工，11女10男，年龄感27—52岁，不代表真实人物、履历或能力实测。年龄和性别不限定职能。

## 统一肖像规则

可爱的高质量Q版3D动画成年职业角色，约3头身（2.5—3头身），大头小身，脸型在圆、心形、方圆与长椭圆之间变化；眼型、眉形、笑容和姿态逐人区分；简化圆润五官，光滑黏土软胶3D材质，发束如数字雕塑，不画真人皮肤毛孔，不使用照片或正常真人比例。单人全身居中，人物占画面约70%高度，四周有足够留白，淡彩纯色背景，温暖柔光。一件岗位道具，无文字无水印无品牌。保留每人不同的脸型倾向、发型、服饰配色和身份标记，年龄差异柔和转译，不画写实皱纹。

每人独立生成，禁止多人合图裁切；人物身份与角色编号保持，不把尚未生成的路径写成现有图片。
